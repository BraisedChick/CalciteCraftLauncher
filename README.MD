**Calcite Craft Launcher** 是一个为 Android 平台设计的 Minecraft 风格客户端/启动器，完全使用 **C++** 编写核心渲染与游戏逻辑，并与 Java/Kotlin 层高效协作。
。

## 📱 系统要求

- Android 8.0 (API 26) 或更高版本
- OpenGL ES 3.0 兼容的 GPU（Vulkan 可选）
- 推荐 2GB RAM 以上
