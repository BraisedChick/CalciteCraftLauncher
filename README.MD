# Calcite Craft Launcher

**Calcite Craft Launcher** 是一个为 Android 平台设计的 Minecraft 客户端/启动器，我们的目的旨在让玩家可以使用原生高性能C++客户端连接Java版服务器。完全使用 **C++** 编写核心渲染与游戏逻辑。


## 📱 系统要求

- Android 8.0 (API 26) 或更高版本
- OpenGL ES 3.0 兼容的 GPU（Vulkan 可选）
- 推荐 2GB RAM 以上
